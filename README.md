# 📚 Library Management System

A fully functional and modern **Library Management System** built using **Flask, Python, HTML, CSS, JavaScript and SQLite3**.

This project helps users to manage books digitally with a clean modern UI and useful library features like borrowing, returning, searching, fine calculation and profile management.

## 🌐 Live Demo

🔗 https://library-management-system-rrb1.onrender.com

---

# ✨ Features

## 👤 Authentication System

* User Registration
* User Login
* Logout System
* Session Handling

## 📚 Book Management

* Add New Books
* Edit Books
* Delete Books
* Search Books
* View Books

## 🔄 Borrow & Return System

* Borrow Books
* Return Books
* Automatic Due Date
* Fine Calculation for Late Return

## 🎨 UI Features

* Modern Glassmorphism Design
* Dark Mode & Light Mode
* Live Clock & Date
* Animated Notifications
* Welcome Popup
* Fully Responsive Layout

## 👤 Profile System

* User Profile Page
* Borrowed Books Counter
* Logout Shortcut

## 📄 Extra Features

* Download PDF Button
* Stylish Footer
* Dynamic Navbar
* Smooth Hover Effects

# 🚀 How To Run

## 1️⃣ Clone Repository

```bash
git clone https://github.com/kamalesh3107ak-ux/library-management-system.git
```

## 2️⃣ Open Project Folder

```bash
cd library-management-system
```

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Flask App

```bash
python app.py
```
